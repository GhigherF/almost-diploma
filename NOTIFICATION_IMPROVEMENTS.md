# Улучшения уведомлений

## ✅ Что добавлено

### 1. Уведомления о бане/разбане

**Backend** (`backend/controllers/usersController.js`):
- При блокировке пользователя отправляется уведомление типа `user_banned`
- При разблокировке отправляется уведомление типа `user_unbanned`
- Сообщения:
  - **Бан**: "Ваш аккаунт был заблокирован администратором. Вы не можете публиковать посты и комментарии."
  - **Разбан**: "Ваш аккаунт был разблокирован. Вы снова можете публиковать посты и комментарии."

### 2. Красный кружок с количеством уведомлений

**Frontend** (`frontend/src/components/NotificationPanel.js`):
- Красный бейдж с количеством непрочитанных уведомлений уже был реализован
- Отображается на кнопке-триггере (🔔)
- Автоматически исчезает при открытии панели
- Обновляется каждые 30 секунд

**Как работает:**
```javascript
{unread > 0 && <span className="notif-panel-badge">{unread}</span>}
```

## 🎨 Визуальное оформление

### Бейдж:
- **Цвет**: Красный (`var(--danger)`)
- **Размер**: 18x18px
- **Позиция**: Правый верхний угол кнопки
- **Шрифт**: 10px, жирный
- **Форма**: Круглый
- **Граница**: 2px белая

### Кнопка с уведомлениями:
- **Обычное состояние**: Серая иконка 🔔
- **С непрочитанными**: Красная иконка 🔔 + красный бейдж с числом
- **При наведении**: Выезжает больше, меняет цвет на акцентный

## 🔔 Типы уведомлений

Теперь поддерживаются следующие типы:

1. **post_deleted_by_admin** - Пост удалён администратором
2. **user_banned** - Пользователь заблокирован
3. **user_unbanned** - Пользователь разблокирован

## 🧪 Тестирование

### Проверка уведомления о бане:

1. Войдите как администратор (alice)
2. Перейдите в профиль другого пользователя
3. Нажмите кнопку "🚫 Заблокировать"
4. Войдите как заблокированный пользователь
5. Проверьте панель уведомлений - должно появиться уведомление о бане
6. Красный кружок с "1" должен появиться на кнопке 🔔

### Проверка бейджа:

1. Создайте несколько уведомлений (удалите посты, забаньте пользователей)
2. Войдите как пользователь с уведомлениями
3. Красный кружок должен показывать количество непрочитанных
4. При наведении на 🔔 панель открывается
5. После открытия бейдж исчезает (уведомления помечаются прочитанными)

## 💡 Дополнительные возможности

Бейдж автоматически:
- Показывает количество непрочитанных уведомлений
- Обновляется каждые 30 секунд
- Исчезает при открытии панели
- Появляется снова при получении новых уведомлений
- Работает в реальном времени

## 🎯 Поведение

1. **Администратор банит пользователя** → Пользователь получает уведомление
2. **Пользователь видит красный кружок** → Наводит на 🔔
3. **Панель открывается** → Уведомления помечаются прочитанными
4. **Красный кружок исчезает** → Пользователь прочитал уведомления
5. **Администратор разбанивает** → Новое уведомление, красный кружок снова появляется
