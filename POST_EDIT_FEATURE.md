# Функция редактирования постов

## ✅ Что добавлено

### Backend
1. **Новая функция в контроллере** (`backend/controllers/postsController.js`):
   - `updatePost()` - редактирование текста поста
   - Проверка прав доступа (только автор может редактировать)
   - Обновление поля `updated_at`

2. **Новый роут** (`backend/routes/postsRoutes.js`):
   - `PATCH /api/posts/:id` - редактирование поста
   - Требует авторизацию
   - Принимает `{ body: "новый текст" }`

3. **Миграция БД**:
   - Добавлено поле `updated_at` в таблицу `posts`
   - Для существующих постов установлено значение `created_at`

### Frontend
1. **UI для редактирования** (`frontend/src/pages/UserPostsTab.js`):
   - Кнопка ✏️ "Редактировать" для своих постов
   - Форма редактирования с textarea
   - Кнопки "Сохранить" и "Отмена"
   - Индикатор "(изм.)" для отредактированных постов

2. **Стили** (`frontend/src/pages/ProfilePage.css`):
   - Стили для формы редактирования
   - Стили для кнопок
   - Адаптивный дизайн

## 🎯 Как использовать

1. Откройте свой профиль
2. Перейдите на вкладку "Посты"
3. Нажмите кнопку ✏️ на любом своём посте
4. Отредактируйте текст
5. Нажмите "✓ Сохранить" или "✕ Отмена"

## 🔒 Безопасность

- Редактировать можно только **свои** посты
- Администраторы **не могут** редактировать чужие посты (только удалять)
- Проверка прав доступа на бэкенде
- Валидация: текст не может быть пустым

## 📝 Особенности

- **Индикатор редактирования**: Если пост был отредактирован, рядом с датой появляется "(изм.)"
- **Сохранение файлов**: Файлы прикреплённые к посту остаются без изменений
- **История**: Поле `updated_at` хранит время последнего редактирования
- **Реактивность**: После сохранения пост обновляется без перезагрузки страницы

## 🧪 Тестирование

### Проверка API
```bash
# Получить токен (войти как alice)
TOKEN="your_jwt_token"

# Редактировать пост
curl -X PATCH http://localhost/api/posts/1 \
  -H "Authorization: Bearer $TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"body":"Обновлённый текст поста"}'
```

### Проверка в UI
1. Войдите в систему
2. Создайте новый пост
3. Перейдите в свой профиль → Посты
4. Нажмите ✏️ на созданном посте
5. Измените текст и сохраните
6. Проверьте, что появился индикатор "(изм.)"

## 📊 Структура данных

### Запрос
```json
{
  "body": "Новый текст поста"
}
```

### Ответ
```json
{
  "id": 1,
  "user_id": 1,
  "body": "Новый текст поста",
  "deleted": false,
  "created_at": "2026-05-19T20:00:00.000Z",
  "updated_at": "2026-05-19T23:25:00.000Z"
}
```

## ⚠️ Ограничения

- Нельзя редактировать **удалённые** посты
- Нельзя редактировать **чужие** посты
- Нельзя редактировать **файлы** (только текст)
- Текст не может быть **пустым**
