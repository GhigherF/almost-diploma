# Unit Tests Documentation - Backend API

## Обзор

Этот документ описывает 17 unit-тестов для backend API приложения Microblog. Тесты охватывают основные функции: аутентификацию, операции с постами, комментариями, пользователями и обработку ошибок.

## Структура Тестов

### Файлы
- **index.test.js** - Основной файл с 17 unit-тестами и mocks для изоляции зависимостей

### Фреймворк
- **Jest** - Популярный фреймворк для unit-тестирования в Node.js

## Использованные Моки

### 1. Mock Pool (PostgreSQL)
```javascript
const mockPool = {
  query: jest.fn(),  // Для всех SQL запросов
  connect: jest.fn(),
  end: jest.fn(),
};
```

**Примеры использования:**
```javascript
// Успешный результат
mockPool.query.mockResolvedValueOnce({ rows: [{ id: 1, name: 'Alice' }] });

// Ошибка
mockPool.query.mockRejectedValueOnce(new Error('DB Error'));

// Пустой результат
mockPool.query.mockResolvedValueOnce({ rows: [] });
```

### 2. Mock JWT
```javascript
jest.mock('jsonwebtoken');

// Мокирование подписи токена
jwt.sign.mockReturnValue('jwt_token_here');

// Мокирование проверки токена
jwt.verify.mockImplementation(() => {
  throw new Error('Invalid token');
});
```

### 3. Mock bcrypt
```javascript
jest.mock('bcrypt');

// Мокирование хеширования пароля
bcrypt.hash.mockResolvedValue('hashed_password_here');

// Мокирование сравнения пароля
bcrypt.compare.mockResolvedValue(true);
```

## Изоляция Зависимостей

Все внешние зависимости мокированы для обеспечения чистоты тестов:

1. **Database Pool** - Замена реальных SQL запросов на mock функции
2. **JWT Library** - Замена настоящей генерации токенов на mock
3. **bcrypt** - Замена реального хеширования на mock функции

Это позволяет:
- ✅ Тестировать код без БД
- ✅ Не требует запуска реального приложения
- ✅ Тесты выполняются за миллисекунды
- ✅ Избегаем побочных эффектов

## Примеры Mock использования

### Mock успешного результата
```javascript
mockPool.query.mockResolvedValueOnce({
  rows: [{ id: 1, email: 'user@example.com' }]
});
```

### Mock ошибки
```javascript
mockPool.query.mockRejectedValueOnce(
  new Error('Database connection failed')
);
```

### Mock с проверкой параметров
```javascript
mockPool.query.mockImplementation((sql, params) => {
  if (params[0] === 'invalid@') {
    throw new Error('Invalid email');
  }
  return Promise.resolve({ rows: [] });
});
```
