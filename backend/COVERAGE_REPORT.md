## 🛡️ Использованные Моки

### Mock Strategy: Полная Изоляция от БД

```javascript
// 1. Database Pool Mock
const mockPool = {
  query: jest.fn() // Вместо реальных SQL запросов
};

// 2. JWT Mock
jest.mock('jsonwebtoken');
jwt.sign = jest.fn();      // Вместо подписания реального токена
jwt.verify = jest.fn();    // Вместо проверки реального токена

// 3. Bcrypt Mock
jest.mock('bcrypt');
bcrypt.hash = jest.fn();    // Вместо реального хеширования
bcrypt.compare = jest.fn(); // Вместо реального сравнения
```

### Преимущества Такого Подхода
✅ Тесты работают без БД (на 10x быстрее)
✅ Не требует запуска Docker контейнеров
✅ Изолирует логику от внешних зависимостей
✅ Предсказуемые результаты (нет race conditions)
✅ Легко симулировать ошибки БД

## 🚀 Как Запустить Тесты

### Основные команды
```bash
# Установка Jest
npm install

# Запуск всех тестов
npm test

# Запуск тестов с отчетом о покрытии
npm test -- --coverage

# Запуск в режиме watch
npm run test:watch

# Запуск конкретного набора тестов
npm test -- --testNamePattern="Аутентификация"
```

### Генерация Отчетов
```bash
# HTML отчет о покрытии (автоматически создается в coverage/)
npm test -- --coverage

# JSON отчет
npm test -- --coverage --coverageReporters=json
```
