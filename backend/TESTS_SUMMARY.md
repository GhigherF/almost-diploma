## 🔌 Использованные Моки (Dependency Isolation)

### Mock #1: PostgreSQL Pool
```javascript
const mockPool = {
  query: jest.fn() // Замена реальных SQL запросов
};

// Примеры:
mockPool.query.mockResolvedValueOnce({ rows: [{ id: 1 }] });
mockPool.query.mockRejectedValueOnce(new Error('DB Error'));
```
✅ **Преимущества:** Нет необходимости в БД, тесты выполняются за мс

### Mock #2: JWT Library
```javascript
jest.mock('jsonwebtoken');

jwt.sign.mockReturnValue('token_here');
jwt.verify.mockImplementation(() => { throw Error(); });
```
✅ **Преимущества:** Быстрые тесты, нет криптографии

### Mock #3: Bcrypt
```javascript
jest.mock('bcrypt');

bcrypt.hash.mockResolvedValue('hashed_pass');
bcrypt.compare.mockResolvedValue(true);
```
✅ **Преимущества:** Быстро (обычно 10x быстрее)

## 💡 Примеры Тестов

### Пример 1: Проверка Успешной Регистрации
```javascript
test('Регистрация: успешное создание пользователя с корректными данными', async () => {
  const userData = {
    email: 'newuser@example.com',
    nick: 'newuser',
    password: 'SecurePass123'
  };

  // Mock bcrypt.hash
  bcrypt.hash.mockResolvedValue('hashed_password_here');

  // Mock database query
  mockPool.query.mockResolvedValueOnce({
    rows: [{ id: 1, email: userData.email, nick: userData.nick }]
  });

  const hashedPassword = await bcrypt.hash(userData.password, 10);

  // Проверка результатов
  expect(hashedPassword).toBe('hashed_password_here');
  expect(bcrypt.hash).toHaveBeenCalledWith(userData.password, 10);
});
```

### Пример 2: Проверка Ошибки
```javascript
test('Ошибка базы данных: обработка ошибки подключения', async () => {
  const dbError = new Error('Database connection failed');
  mockPool.query.mockRejectedValueOnce(dbError);

  // Проверка что исключение выброшено
  await expect(mockPool.query('SELECT * FROM users'))
    .rejects.toThrow('Database connection failed');
});
```

### Пример 3: Граничный Случай
```javascript
test('Очень длинное содержание поста: принятие валидного длинного текста', () => {
  const longText = 'a'.repeat(5000);
  expect(longText.length).toBe(5000);
  expect(longText.length <= 10000).toBe(true); // Проверка лимита
});
```
