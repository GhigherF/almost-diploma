# Design System Specification

## Color Palette

### Primary Colors
- Main Blue: #5ba3d0
- Dark Blue: #2c5aa0
- Light Blue: #a8d5f7

### Secondary Colors
- Orange: #db8a52
- Purple: #7e5cb0
- Green: #4caf50

### Neutral Colors
- Dark Gray: #333333
- Medium Gray: #666666
- Light Gray: #cccccc
- White: #ffffff

## Typography

### Headings
- H1: 32px, Bold, Primary Blue
- H2: 24px, Bold, Dark Gray
- H3: 20px, Semi-bold, Dark Gray

### Body Text
- Regular: 16px, Normal, Dark Gray
- Small: 14px, Normal, Medium Gray

## Component Spacing

- XS: 4px
- SM: 8px
- MD: 16px
- LG: 24px
- XL: 32px

## Button Styles

- Primary: Background Blue, White Text
- Secondary: Border Gray, Dark Text
- Danger: Background Red, White Text
- Disabled: Background Light Gray, Gray Text, 50% opacity

## Responsive Breakpoints

- Mobile: < 640px
- Tablet: 640px - 1024px
- Desktop: > 1024px
