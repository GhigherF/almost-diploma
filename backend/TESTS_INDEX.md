## 📚 Справочный Материал

### Моки (Как они Работают)

**Database Mock:**
```javascript
mockPool.query.mockResolvedValueOnce({ rows: [...] })  // Success
mockPool.query.mockRejectedValueOnce(new Error(...))   // Error
```

**JWT Mock:**
```javascript
jest.mock('jsonwebtoken');
jwt.sign.mockReturnValue('token')
jwt.verify.mockImplementation(() => { throw Error() })
```

**Bcrypt Mock:**
```javascript
jest.mock('bcrypt');
bcrypt.hash.mockResolvedValue('hashed')
bcrypt.compare.mockResolvedValue(true)
```

**Где найти:** TESTS_README.md раздел "Использованные Моки"
